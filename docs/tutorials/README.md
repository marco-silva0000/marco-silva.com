# Tutorials: Party Games Platform (Quadrant 1: Learning-Oriented Lessons)

Welcome to the **Tutorials** quadrant for the party games platform on `marco-silva.com`.

Adhering strictly to the **Diátaxis documentation framework**, these tutorials are learning-oriented lessons designed for beginners. They guide new players and hosts through a linear, zero-friction path from creation to completion of their very first game round. They avoid branching choices, edge cases, and theoretical digressions in favor of immediate hands-on learning.
